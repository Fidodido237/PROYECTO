# Login Project 🚀

This repository contains a modern, full-stack **Login Project** built with Next.js. It features a complete authentication architecture separating front-end presentation from back-end API route management.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** MongoDB (NoSQL)
- **Version Control:** Git & GitHub (Feature-Branch Workflow)

---

## 📦 Project Structure

The project follows a clean architecture based on Next.js standards:

- `app/`: Contains the core application logic and views.
  - `api/`: Back-end layer exposing API endpoints for data handling.
  - `page.tsx`: Main entry point / Landing view.
- `CHANGELOG.md`: Strict historical log of all notable changes following the *Keep a Changelog* standard.
